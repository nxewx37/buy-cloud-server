3. **选地域**。大陆地域国内访问快，但用来建网站需要完成 ICP 备案；不想备案就选香港或境外地域，代价是国内访问延迟高一些。地域买定后不能更换，迁移只能重买，这一步别随手选。

6. **确认订单并付款**。订单页核对三样东西：配置明细、计费周期、续费价格。很多特价机型首年便宜、次年按标准价续费，这一眼值几十上百块。

## 付款之后：第一次连接服务器

新服务器第一次连不上，原因九成出在两件事上：密码没设置，或者端口没放行。

先说端口。安全组相当于服务器门前的防火墙，默认只放行少数端口：SSH 走 22，Windows 远程桌面走 3389，网页服务常用 80、8080。你用哪种连接方式，就确认对应端口在安全组规则里是放行状态。新手阶段用默认规则即可，需要时再逐条添加；用不到的端口不要随手开放——开一个端口，等于允许全网 IP 来敲门。

连接方式有三种，按方便程度排：

- **SSH 命令行**：Windows 按 Win+R 输入 cmd 打开命令行（Mac/Linux 直接开终端），执行 `ssh root@你的公网IP`，输入密码即可登录 Linux 服务器。不想每次敲 IP 和密码，可以用 Xshell 这类工具保存会话。
- **远程桌面**：服务器是 Windows 系统时用。系统里允许远程连接后，用本机远程桌面工具填公网 IP 登录。
- **控制台远程连接**：前两种都失败时的兜底方案，登录云服务器管理控制台，在实例列表点远程连接直接进系统。

安全上有一条建议值得马上做：把 SSH 默认的 22 端口改掉。编辑 `/etc/ssh/sshd_config`，把 Port 改成其他值，再到安全组放行新端口，以后用 `ssh -p 端口号 root@IP` 连接。公网上的扫描器 24 小时在试探 22 端口，改个端口能过滤掉大部分噪音。

**域名必须备案吗？**
用大陆地域的服务器对外提供网站服务，域名需要 ICP 备案；香港和境外地域免备案。备案本身免费，但要等审核通过才能访问，赶时间的项目直接选免备案地域更省事。
